A version update of the PlayOnline Friend List Application was performed at the following time. The client program updates automatically the next time the application is started.

Date/time: Tuesday, November 21, 2006, around 16:00 (JST)
Affected: PlayOnline Friend List Application users

Main changes:

  • Fixed an issue where a group could not be selected when choosing "Start Group Chat" while the blocked list was displayed.
  • Fixed an issue where part of the window did not display correctly in specific environments.
  • Fixed an issue where the window could appear in the wrong position depending on taskbar placement.
  • Fixed an issue where certain operations could push read messages past the 200-message limit.
  • Fixed other minor issues.
