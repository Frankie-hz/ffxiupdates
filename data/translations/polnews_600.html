Server maintenance accompanying a FINAL FANTASY XI version update will be performed at the following time.

Date/time: Tuesday, August 26, 2003, 5:00 to around 11:00 (JST)
Affected: FINAL FANTASY XI players

Main changes:

  • Fixed an issue where guards at each nation's consulates would introduce themselves as the "Ducal Guard of Jeuno."
  • Fixed an issue where transferring allegiance to another nation could incorrectly warn that "individual conquest points will be lost."
  • Corrected the help text of Stun Claws, Rising Sun +1, and the Berserker's Axe.
  • Fixed an issue where the widened area of effect of bard songs sung with stringed instruments was not working.
  • Fixed an issue where the HP/MP gauge color was slightly darkened when fully restored.
  • Fixed an issue where some Goblins had stopped dropping gil.
  • Renamed "Fungus Cap" to "Fungus Hat" for consistency with the English version.
  • Fixed a state where the message-log flush processing could cause momentary freezes when many log lines scroll by in battle ("PlayStation 2" version only).
  • Fixed an issue with the pumpkin pie synthesis recipe.
  • Fixed an issue where a pet could be given "Reward" after Final Sting.
  • Fixed an issue in the region and item screens where the hardware mouse cursor switched too frequently (Windows version only).
  • Fixed a case where the mouse cursor could react during text completion/kanji conversion in some environments (Windows version only).
  • Fixed an issue in some Zilart-area fields where light reflecting off metal armor could rarely appear white (Windows version only).
  • Fixed English-version messages and several other issues.
