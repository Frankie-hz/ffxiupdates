A version update of the PlayOnline Viewer will be performed at the following time. This update also updates the client program; after the date below, the client will update automatically at your next login. Follow the on-screen instructions.

Date/time: Tuesday, August 19, 2003, around 16:00 (JST)
Affected: PlayOnline Viewer users

Main changes:

  • Changed part of the main menu layout.
  • Added English (US-ASCII) to the mail encoding types.
  • Fixed the FINAL FANTASY CRYSTAL CHRONICLES wallpaper icon.
  • Fixed an issue where the friend list could malfunction while viewing content.
  • Fixed an issue where error 12288 could occur during a version update.
  • Fixed an issue where mail sending could hang for a long time with the progress bar at 100%.
  • The PlayOnline mail server now supports POP before SMTP. Mail sent and received through the PlayOnline Viewer is unaffected; if you use other mail software, change its settings to use POP before SMTP (a mechanism that authenticates the sender by connecting to the receiving mail server before sending).
