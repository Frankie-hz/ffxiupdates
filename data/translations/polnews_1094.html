As announced in "All Worlds Maintenance (12/9)", server maintenance including character migration to the Asura world (applicants only) will be performed Tuesday, December 9, 2003, 2:00 to around 10:00 (JST).

If a character migrates worlds, any PlayOnline Plus character name address obtained under that character name becomes invalid.

Affected: customers using a PlayOnline Plus character name address whose character undergoes world migration.

Because renaming may also be required by the migration, first log in to FINAL FANTASY XI after the maintenance and complete any procedures shown on screen, then reconfigure the address: from the PlayOnline Viewer main menu, go to Topics, then PlayOnline Plus, then Character Name Address, then Confirm/Configure, and set up the address for the new world name and character name.
