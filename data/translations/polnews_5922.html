A version update of the PlayOnline Friend List Application beta was performed at the following time.

Date/time: Tuesday, October 25, 2005, around 17:00 (JST)
Affected: PlayOnline Friend List Application beta users

Main changes:

  • Added support for "Fantasy Earth: The Ring of Dominion" (beta test scheduled to begin October 27): selecting "Friend List" from the in-game menu now shows the friend list on the game screen, and friends playing Fantasy Earth are shown with the corresponding content icon.
  • Added keyboard controls: the arrow keys show an anchor, Enter confirms, Esc cancels.
  • Fixed an issue where hiding the friend list via "Show Desktop" on the Windows quick launch bar made it impossible to restore the original size.
  • Fixed a display issue on the Windows taskbar (Windows XP only).
  • Fixed other minor issues.
