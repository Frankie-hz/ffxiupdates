All Users

  • Signet duration has changed: the lower your nation's conquest ranking, the longer the Signet. From rank 7 onward: 1st-place nation 2-10 hours by rank (1 through 9+), 2nd place 3-11 hours, 3rd place 4-12 hours (Earth time).
  • Changing fishing rod or bait no longer resets TP to 0; equipping a boomerang now does reset TP.
  • Shop stock: the Tenshodo now sells black pepper and mid-level great katana; the Culinarians' Guild now sells smoked salmon.
  • Windows version: character loading has been improved, and a sound driver bug was fixed.
  • Fixed: auction listing text could display corrupted; blackout when logging out during Mog House layout or gardening menus; the level 61+ experience rule change was mistakenly applied at 60 (experience now reflects your own level versus the enemy and relaxed party level-difference correction); Sneak and Deodorize were not breaking when opening treasure chests; Monk's Kick Attacks damage was weakened by ranged slot equipment.
  • The spell recast display "Last" has been changed to "Next."
  • The three San d'Orian high priests now use their real names: Croisque becomes Chasalvige, Vicasque becomes Halaviabeau, Evesque becomes Olbergieut.
  • Item fixes: the scroll of Absorb-DEX was misnamed "Absorb-TEC"; "Dangruf sulfur" renamed to "sulfur"; Battle Boots equip level 60 corrected to 59; Dark Axe +1 damage 42 corrected to 43; several keys could not be used from the item list via "Use."
  • Following the Fast Cast revision, the casting of these red-mage-type monsters was not behaving as intended and has been fixed: Polevik, Vaa Huja the Erudite, Wandering Ghost, Miser Murphy, Gerwitz's Soul, Bugaboo, Magic Sludge, Chaos Elemental, Boreal Coeurl.
  • These monsters now drop gil: Ancient Goobbue, Voluptuous Vivian, Cemetery Cherry, Adamantoise.
  • Summoner-type beastmen now summon avatars other than Carbuncle.
  • Along with renaming golem-family drops, "golem shard" is now "doll shard," and Crystal Giants now drop golem shards.
  • Mandragora's Leaf Dagger corrected from area effect to single target.
  • Fixed: the beastmaster jug pet "Courier Carrie" (蜻蛉のしもべ) would not use techniques under Sic.
  • New pronoun <pethpp> returns your pet's remaining HP% (pet must be in targeting range). With a pet out, its name and HP gauge (when in range) now display at the upper right of the log window. "Check" has been added to the action commands for your charmed pet. /pet no longer triggers abilities unrelated to pets.
  • PS2 ATOK input feel improved: the candidate window closes when there are no conversion candidates, and unconfirmed text is discarded when switching input modes.
  • Ctrl/Alt+B added as a shortcut to the pet command menu. Using an ability from the menu now returns you one menu level back. Fixed maps/region info occasionally failing to close. Mog Safe check now reflects linkshell/sack/pearl names and colors. Fixed being unable to use Mog Safe check while riding a chocobo.
  • Guild shops and the auction house now color-code equippable weapons, currently equipped weapons, learned spells, and learnable spells (summoning magic excluded). Auction stack listings changed color from yellow to deep pink. Returning from sales history no longer refreshes the list.
  • Linkshell member lists now show the same name colors, search comment marks, and comment access as regular search results.
  • Fixed macros failing to equip two identical items to different slots from separate lines. While target lock is on, the cancel button alone no longer drops the target - use the lock button again.
  • Fixed the Mog House help text for the main menu button. The new-mail indicator now blinks more slowly when there is mail but no new messages. The map screen now prioritizes the party member list when members are in targeting range, then fills in others via area search.
  • Fixed: creating a second character on a world where you already have one (world name only, no pass needed) had been broken since the previous update.
