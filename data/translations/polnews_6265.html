A version update of the PlayOnline Friend List Application beta was performed at the following time.

Date/time: Wednesday, December 14, 2005, around 16:00 (JST)
Affected: PlayOnline Friend List Application beta users

Main changes:

  • Fixed an issue where search result text did not display correctly when using Q&A search from a supported game's Support Desk.
  • Fixed an issue where suspending a GM chat started from a supported game's Support Desk made it impossible to resume the chat.
  • Fixed an issue where the GM call state persisted after a GM chat ended, e.g. the [GM] icon not disappearing from the PlayOnline Viewer screen.

The Friend List and Support Desk of games that use this application as standard (currently only the Fantasy Earth: The Ring of Dominion beta) are provided by this application's functionality.
