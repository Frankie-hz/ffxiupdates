A version update of the PlayOnline Friend List Application beta was performed at the following time. The client program updates automatically the next time the application is started.

Date/time: Tuesday, November 22, 2005, around 16:00 (JST)
Affected: PlayOnline Friend List Application beta users

Main changes:

  • Fixed an issue where "Add to blocked list" could be selected from the right-click menu of a group disbandment notification message.
  • Fixed an issue where receiving a new message while 200 received messages were locked would delete locked messages.
  • Fixed an issue where the friend list display did not update correctly when the active handle changed on starting a game that uses the application (currently only the Fantasy Earth: The Ring of Dominion beta).
  • Fixed an issue where pressing Esc with a window like "Edit Comment" open while such a game was running closed every friend list window.
  • Fixed other minor issues.
