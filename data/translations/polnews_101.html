Every retail package of FINAL FANTASY XI & PlayOnline, whether the "PlayStation 2" or Windows version, contains a "registration code sheet" listing registration codes for the following PlayOnline content (each code is a 20-character alphanumeric string separated by hyphens):

  • PlayOnline
  • FINAL FANTASY XI
  • Tetra Master
  • JanHoRo ("PlayStation 2" version only)

The PlayOnline registration code is required when joining PlayOnline, and each content's registration code is required when purchasing that content's content ID.

If a registration code is lost, no further content ID purchases can be made with it. Registration codes cannot be reissued for any reason; if you still wish to purchase a content ID after losing the code, you would have to buy a new retail package.

Registration codes are essential for your continued use of the service. Please keep the entire sheet in a safe place and never lose it.
