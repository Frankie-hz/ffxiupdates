With the PlayOnline Viewer version update, PlayOnline can now use "additional dictionaries" containing text-conversion words specialized for each content title ("PlayStation 2" version only).

The new "Additional Dictionary Download" corner in Topics is where these can be downloaded. Registering a downloaded dictionary via the PlayOnline Viewer options makes it easy to convert words commonly used in each title. Dictionaries for more titles will be added over time. See "Additional Dictionary Download" in Topics for details.
