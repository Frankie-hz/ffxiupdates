When installing the "PlayStation 2" version of the FINAL FANTASY XI Chains of Promathia expansion data disc, interrupting the installation with the "Cancel" button makes a full reinstall necessary, including the FINAL FANTASY XI data itself.

A confirmation message to this effect is displayed when you press "Cancel".

Because of this, redoing the installation requires the FINAL FANTASY XI disc, so please have it at hand.

The same state also results if installation fails for any other reason, even without pressing "Cancel"; in that case as well, please start over from the FINAL FANTASY XI installation.
