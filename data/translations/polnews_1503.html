A PlayOnline Viewer version update will be performed at the following time. The client program updates automatically at your next login after this date.

Date/time: Tuesday, February 17, 2004, around 18:00 (JST)
Affected: PlayOnline Viewer users

Main changes:

  • Added an auto-login function: the Viewer can automatically connect to the network and log in to PlayOnline after starting. Set it via the "Auto-login with this member at startup" option shown when executing Login with a member selected. If passwords such as a member password are required, the usual password entry screens still appear.
  • With the addition of auto-login, the opening movie and old title screen were removed; a new title screen now switches to the login screen automatically.
  • The handle name creation screen now appears at first login after joining PlayOnline.
  • In window mode, the window can now be freely resized (Windows version only).
  • Removed the bulk content data download function; new content data is now downloaded automatically when viewing content.
  • Fixed other issues.
