Due to growing world populations, applications for world migration are now open under the following terms. Read carefully before applying.

Eligible: all worlds (priority to the Lakshmi and Seraph worlds)

Application period: Wednesday, September 24, 2003, 18:00 to Wednesday, October 1, 18:00 (JST)

About the migration and destination world:

  • If the number of applicants is judged insufficient to form a world, this migration will be postponed. Whether it proceeds will be announced after the deadline.
  • If character names collide as a result of migration, renaming may be required; please apply with this understanding.
  • Name priority in the event of collisions goes to Lakshmi, currently the most populated world. If enough players apply that two new worlds are created, Seraph has second priority. Character names cannot be guaranteed for migrants from other worlds.

How to apply: from the start of the application period, NPCs named "World Shifter" appear in the following areas. Speaking to one lets you check your character's current application status and set or cancel your application: Ru'Lude Gardens (I-10), Port San d'Oria (I-8), Port Bastok (L-8), Windurst Waters (G-6).

After applications close, no further migration-related operations of any kind will be possible.
