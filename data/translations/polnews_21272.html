An important notice for players using the "PlayStation 2" version of FINAL FANTASY XI on a "PlayStation 3" (60GB model CECHA00 or 20GB model CECHB00).

Following discussions with Sony Computer Entertainment, to support the continued operation of FINAL FANTASY XI, the hard disk capacity required to use the "PlayStation 2" version of FINAL FANTASY XI will be expanded from the current 12GB to 21GB.

This change is planned to be applied in a "PlayStation 3" system software update to be carried out by Sony Computer Entertainment from February 2012 onward.

As a result, players currently using the "PlayStation 2" version on a "PlayStation 3" 20GB model (CECHB00) will no longer be able to secure the required capacity after the update. Please consider replacing the PS3's HDD, or switching to the Windows version.

For questions about operation on "PlayStation 3", contact Sony Computer Entertainment: http://www.jp.playstation.com/support/

Players on "PlayStation 2" hardware are not affected by this change. On "PlayStation 3", a message is displayed if free space is insufficient; free up space or replace the HDD as needed.
