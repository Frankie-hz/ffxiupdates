This applies to the "PlayStation 2" version of the PlayOnline Viewer only. The Windows version is not affected.

When installing PlayOnline-compatible software such as the FINAL FANTASY XI Rise of the Zilart expansion data disc (scheduled for release April 17, 2003) with PlayOnline Viewer version 1.08.04 or earlier, selecting "Install" on the login screen may display the message "Saved data will be overwritten. Reinstall?" even when the software has not yet been installed. This is a display issue only; selecting "Yes" at this point does not overwrite any data.

Note: some PlayOnline-compatible software does overwrite data during installation. Follow the on-screen instructions.

This display issue is scheduled to be fixed in the PlayOnline Viewer version update (1.09.00) planned for Tuesday, April 8, 2003. Before installing PlayOnline-compatible software, always update the PlayOnline Viewer to the latest version first.

The planned version update date was later changed to Thursday, April 10. See "PlayOnline Viewer Update (4/10)" for details.

How to get the latest PlayOnline Viewer: the Viewer checks for and applies version updates automatically at login. If your Viewer is not the latest version, it will update automatically when you log in to PlayOnline. Logging in once before installing PlayOnline-compatible software ensures you are on the latest version.
