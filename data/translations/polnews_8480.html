A version update of the PlayOnline Friend List Application was performed at the following time. The client program updates automatically the next time the application is started.

Date/time: Tuesday, August 29, 2006, around 16:00 (JST)
Affected: PlayOnline Friend List Application users

Main changes:

  • Fixed an issue where, after using Windows "Show Desktop" and then selecting another program's window, the Friend List Application window would also appear.
  • Fixed an issue where "Send Group Message", "Start Group Chat", and "Disband Group" could be selected while not in a group.
  • Changed the application so its button disappears from the Windows taskbar when the window is minimized.
  • Fixed an issue where knock messages sent by a GM could not be marked as read.
  • Fixed other minor issues.
