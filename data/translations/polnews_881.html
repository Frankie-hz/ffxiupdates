Maintenance accompanying a PlayOnline Viewer version update will be performed at the following time. The client program updates automatically at your next login after this date.

Date/time: Tuesday, October 21, 2003, 2:00 to around 14:00 (JST)
Affected: PlayOnline Viewer users

Japanese input system (ATOK):

  • The user dictionary now holds up to 200 words ("PlayStation 2" version only).
  • Updated the system dictionary, adding terms mainly drawn from FINAL FANTASY XI development information. This change is not applied by the version update alone: select the [Repair Dictionary] button under [Text Input Palette]-[Dictionary]-[User Dictionary]; confirming the "Repair user dictionary?" prompt also updates the system dictionary ("PlayStation 2" version only).

PlayOnline Mail:

  • In the address book's "Edit Address" screen, the setting "Refuse mail from this person" was relabeled "Automatically delete mail from this person" to match its actual behavior (it deletes mail after receipt rather than refusing it; a true block function is planned for PlayOnline Plus).
  • Added a signature-insertion function when composing mail.
  • Added support for the "character name addresses" of the upcoming PlayOnline Plus beta: sender selection when composing, per-address sender information, and per-address signatures, configured under Account Management.

Other:

  • Added a "last login time" display to the main menu screen. If a login you do not recognize is shown, a third party may be accessing your account illegitimately; changing your PlayOnline password is recommended ([Service & Support]-[Member Information]-[PlayOnline ID]-[Change Password]).
  • The simple manual is now updated continuously; it currently covers PlayOnline Viewer Ver 1.10.00 ("Basic Controls" and "Login" update only at version updates).
  • Fixed several other issues.
