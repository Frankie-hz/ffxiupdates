Job/tactics

Battle balance: enfeebling resistance: Taniguchi: some asked that enfeebling skill also influence the resistance mechanism. It already does, but the skill difference is not very visible, so we plan to widen it. The resist-hack proc rate will also be tuned more frequent than on the current test server.

The planned large Protect boost: Ito: monster Protect worries some. In practice, monster-cast Protect is meant to be dispelled - there is no undispellable Protect. Yes, many jobs lack removal solo, but you should not solo a battle where Protect decides the outcome.

System

The new Windows UI; fishing; the error on sheathing then immediately drawing: Mochizuki: during verification we considered instant draw plus a delay before the first attack, but that made the post-draw wait very long - about one attack round lost overall; shortening it instead allowed attacking faster than the weapon's true delay. Many such problems led to the current behavior.

Character collision (1-2): Ito: the 10-second rule feels like the fine line before others turn to air. Perception differs by person and there is no single right answer, but development considers this the appropriate reply to the request.
