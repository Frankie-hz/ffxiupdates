• Red Mage gains the exclusive white magic spells Regen (level 21) and Refresh (level 41). Red Mage's enfeebling magic skill cap has been raised.
  • Beastmaster's axe combat skill cap has been raised. Paladin's one-handed axe and great axe skills have been removed.
  • New notorious monsters can now be fought in battlefields via the Burning Circles visited during the Rank 2 mission. These battles come in several level brackets set by entry conditions; players above the bracket are temporarily level-restricted down to it. Prepare equipment for the target level band, or you may end up fighting with your gear unequipped. Your level returns to normal on leaving the battlefield. Existing mission battlefields now also carry level restrictions, shown with an icon (the battlefield key icon has also been redrawn): new battlefields level 40 or 60; Rank 2 mission battlefield level 25; Rank 5 mission battlefield in Fei'Yin level 50.
  • Expeditionary force minimum level requirements have been lowered. To counter adventurer expeditions, beastman armies now dispatch new units protected by the same level restriction system. Players targeted by these units are level-restricted; unrestricted players cannot attack the unit or aid restricted players with cures. The restriction lifts after a time, can be removed by a certain method, or deliberately re-applied; restriction levels are 30, 40, or 50 by region. Defeating these units earns regional points, and successful expeditions add a bonus to individual conquest points.
  • Some fixed-interval notorious monsters now have a randomized spawn delay after server restarts.
  • Inside dungeons only, magic, weapon skills, abilities, items, and ranged attacks now strictly check whether terrain blocks the action. Outdoor field areas and the Attack command behave as before.
  • Area-effect magic is now limited to roughly ±4 meters of vertical range from the target's center (horizontal range unchanged). Together with the previous item, this prevents some notorious monsters' long-range area attacks from catching players on other floors.
  • Opening Treasure Chests and Coffers now removes Sneak and Deodorize (Invisible already prevents opening). A new trap type has been added for thief chest picking.
  • Search comments introduced: each player can set a comment (up to 3 lines) readable from search results. A "comment edit" button was added at the bottom of the search menu ("search by area" moved to the top). Comments are cleared at logout, and no notification is sent when someone reads yours.
  • Party leaders' names now show in yellow in search results, and alliance invites can be sent directly from the list. Auto party matching now limits level spread to ±1 at all level bands.
  • New chat pronouns: <st> (choose a sub-target), <lastst> (last sub-target's name), <stpc> (sub-target PCs only), <stnpc> (sub-target NPCs only), <hp> (current/max HP), <mp> (current/max MP), <hpp> (HP%), <mpp> (MP%), <job> (main/support levels, e.g. "WAR10/MNK5"), <mjob> (main job level), <sjob> (support job level), <bt> (the enemy you are fighting), <scan> (the enemy tracked by Wide Scan), <pet> (your pet's name). The pronoun <ht> announced in dev news was postponed for technical reasons.
  • Macro editing pages can now be flipped with R2/L2 (Windows: the buttons bound to macro palette Ctrl/Alt in the gamepad config). During play, sets switch with R2 or L2 (Alt or Ctrl) plus up/down. Direct keyboard switching changed from Ctrl+Alt+Shift+number to Shift+Ctrl+number and Shift+Alt+number.
  • When accepting a friend request you can now rename the friend as you like (leaving it blank behaves as "close unread").
  • /attack with a pronoun now performs a target change. A /echo command that echoes text to your own log has been added. Ctrl(Alt)+R now cycles the reply target through recent /tell senders. The Ctrl(Alt)+S/R/T/L/P shortcuts now work while the input line is open.
  • A compact keyboard input mode (for keyboards without a numpad) has been added - PS2: Config top button becomes "keyboard input"; Windows: under Config > Misc. 2.
  • When targeting yourself, the action menu now puts "Fish" where "Check" was, keeping the "Trade" command. Pressing Enter before a bite now cancels fishing like the confirm button.
  • Events added to the Bastok missions 「終わらぬ戦い」and 「忘れられた鉱山にて」, with other Bastok events partly changed.
  • The offer condition for "Atop the Highest Mountains" has been relaxed from level 55 to 51. A choice dialog was added to the Delkfutt's Tower warp.
  • Individual conquest point rates changed - being 1st place is now more rewarding and 2nd/3rd earn less. Normal table (own territory rows by rank, multipliers in 1st/2nd/3rd-place/beastman territory): 1st place nation 1.5/1.5/1.5/1.5; 2nd 1.5/1/1.5/1.5; 3rd 1.5/1.5/1/1.5. During an alliance campaign: 1st 1.5/1.5/1.5/1.5; 2nd (allied) 2/1/1/1.5; 3rd (allied) 2/1/1/1.5.
  • Consumable reward items are now available for individual conquest points, shared by all three nations regardless of ranking.
  • After bidding at the auction house, or collecting returned items/proceeds from your post and then checking your listings, a help message now confirms it.
  • The pirate's gun recipe now requires a sub-skill. Dhalmel steak's required skill went down. Sausage roll's shop price went up. Several other bugs were fixed.
  • PS2 version: text input processing changed so ATOK conversion no longer causes momentary slowdowns. The "sync with PlayOnline Viewer auto-offline" feature announced in dev news (February) was postponed.
