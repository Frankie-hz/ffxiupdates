Server maintenance accompanying a FINAL FANTASY XI version update will be performed at the following time. The client program also updates; after maintenance, pressing the Play button starts the update automatically.

Date/time: Tuesday, October 28, 2003, 9:00 to around 11:00 (JST)
Affected: FINAL FANTASY XI players

Main changes:

  • Fixed the issue where some combinations of character face and head equipment did not display correctly.
  • Fixed an issue where the [Ctrl+V] key was inactive on the region info screen.
  • Fixed an issue where target pronouns (<t> etc.) after an auto-translate phrase could fail to convert.
  • Fixed an issue where using target pronouns (<st> etc.) in a macro moved both the sub-target cursor and the action command window's menu cursor at the same time.
  • Fixed an issue where using <st> in a macro prevented camera control with the keyboard cursor keys.
  • Fixed an issue where confirming with the mouse while using <st> in a macro would select an item in the item list instead.
  • Fixed an issue where using certain enfeebling magic on a monster could cause the target to stop moving from that spot.
  • Corrected the parameters of the kingdom lancer's horn +1 and +2.
  • Fixed an issue where [Shift+Tab] had become inactive (Windows version only).

Known issue still under investigation: with a sub-target cursor displayed via <st> in a macro, the software keyboard cannot be operated with the mouse ("PlayStation 2" version only).
